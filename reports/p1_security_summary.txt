[ Changes ]
  P1-1: Message size limit
    - MaxMessageSize = 64KB (configurable via SecurityConfig)
    - Oversized messages → disconnect
    - Applied to both FrameReader and standalone ReadFrame

  P1-2: Rate limiting
    - RateLimiter per connection (100 msg/sec default)
    - Exceeding limit → disconnect
    - Configurable via SecurityConfig.MaxMessagesPerSec

  P1-3: Goroutine panic recovery
    - Room.tickLoop has defer recover()
    - Single room panic stops only that room
    - Logged: "[Room N] PANIC recovered: ..."

  P1-4: Token authentication
    - -token flag enables auth (empty = disabled)
    - Client sends token in SessionBind.Data
    - Bad token → playerId=0 response
