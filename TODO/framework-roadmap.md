# BoomNetwork 框架推广 — 紧急重要四象限

## 一、紧急且重要（立即做，阻断别人使用）

| # | 任务 | 现状 | 目标 |
|---|------|------|------|
| 1 | **README + Quick Start** | 无 | 5 分钟跑通：克隆→启动服务器→Unity 连接→看到方块移动 |
| 2 | **Unity 集成指南** | 无 | 最小接入代码：添加 UPM 包→创建 Person→连接→收帧→渲染 |
| 3 | **服务器部署** | 只有 go run | Dockerfile + docker-compose + 编译好的二进制发布 |
